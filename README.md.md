# AI Voice Studio & Chat Assistant

Минималистичный веб-интерфейс для работы с нейросетью Llama 3.3 через API Groq Cloud. Приложение поддерживает голосовой ввод (Speech-to-Text), потоковое форматирование ответов с подсветкой кода и встроенный плеер для озвучивания текстов (Text-to-Speech) с возможностью ставить паузу и возобновлять воспроизведение.

---

## 🚀 Основные возможности

- **Запросы к LLM:** Интеграция с Groq API (`llama-3.3-70b-versatile`).
- **Голосовой ввод (STT):** Распознавание речи прямо в браузере через Web Speech API.
- **Озвучка ответов (TTS):** Синтез речи для ответов с кнопками управления (`Пауза`, `Продолжить`, `Стоп`).
- **Форматирование кода и Маркдауна:** Полноценный рендеринг Markdown (списки, таблицы, заголовки) и синтаксическая подсветка кода через `react-syntax-highlighter`.
- **Адаптивный интерфейс:** Автоматически подстраивающаяся по высоте текстовая область и прокрутка к последнему сообщению.

---

## 🛠 Технологический стек

- **Фреймворк:** React, TypeScript
- **Сборщик:** Vite
- **Стилизация:** Tailwind CSS
- **Рендеринг текста:** `react-markdown`, `remark-gfm`
- **Подсветка кода:** `react-syntax-highlighter`
- **API:** Groq API Cloud
- **Browser APIs:** Web Speech API (SpeechRecognition & SpeechSynthesis)

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта и укажите ваш API-ключ от Groq:

```env
VITE_GROQ_API_KEY=gsk_your_groq_api_key_here
```

> Получить ключ можно в панели управления [Groq Cloud Console](https://console.groq.com/).

### 4. Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

## 💡 Известные особенности браузеров

- **Голосовой ввод (STT):** Функция распознавания речи работает на базе `window.SpeechRecognition` (или `webkitSpeechRecognition`) и наилучшим образом поддерживается в браузерах на базе Chromium (Google Chrome, Microsoft Edge, Brave).
- **Синтез речи (TTS):** Озвучивание осуществляется встроенным движком `window.speechSynthesis`. Доступность и качество голосов зависят от операционной системы и браузера.
