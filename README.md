# Голосовой ИИ ассистент по коду

Интерактивное веб-приложение на React и TypeScript с поддержкой голосового ввода, синтеза речи и интеграцией с Groq API.

## Основной функционал

- 💬 **ИИ-чат:** Отправка текстовых запросов через Groq API с рендерингом ответа в формате Markdown.
- 🎙️ **Голосовой ввод:** Распознавание речи через Web Speech API.
- 🔊 **Озвучивание ответов:** Синтез речи (Web Speech API) с возможностью паузы и возобновления.
- 🛡️ **Защита запросов:** Встроенный кулдаун и ограничение частоты запросов (1 в мин).
